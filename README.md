# 🔥 What I'm Building

## 🧩 Code Story Studio

<p align="center">
  <img src="https://img.shields.io/badge/Project-Code%20Story%20Studio-00F7FF?style=for-the-badge&logo=codeforces&logoColor=white" />
</p>

> **"Don't just read the code. See the code execute."**

An interactive **code execution visualization platform** designed to help beginners understand programming by visually showing what happens during execution.

### ✨ Features

```text
Code
 │
 ▼
┌─────────────────────┐
│   Code Execution    │
└──────────┬──────────┘
           │
           ▼
┌─────────────────────┐
│   Execution Trace   │
└──────────┬──────────┘
           │
     ┌─────┼─────┐
     ▼     ▼     ▼
   Code  Memory  Output
     │     │     │
     └─────┼─────┘
           ▼
┌─────────────────────┐
│ Interactive Visual  │
│     Execution       │
└─────────────────────┘
```

* ▶️ Step-by-step execution
* ⏸️ Pause / Resume
* ⏭️ Next / Previous line
* 🧠 Variable visualization
* 💾 Memory visualization
* 📚 Line-by-line explanations
* 📊 DSA visualizations
* 🐍 Python support
* ☕ Java support
* ⚙️ C / C++ support
* 🟨 JavaScript support
